# Caso de Uso - Sistema de Gestão de Estoque

## Ator

### Administrador do Estoque

É o usuário responsável pelo gerenciamento dos produtos disponíveis no estoque do mercado.

## Casos de Uso

### Cadastrar Produto

O administrador informa os dados do produto e solicita o cadastro.

Dados necessários:

- Nome;
- Categoria;
- Descrição;
- Preço;
- Quantidade;
- Data de validade.

### Listar Produtos

O administrador pode visualizar todos os produtos cadastrados no sistema.

### Visualizar Produto

O administrador pode visualizar as informações completas de um produto específico.

### Editar Produto

O administrador pode alterar as informações de um produto já cadastrado.

### Excluir Produto

O administrador pode excluir um produto do estoque.

Antes da exclusão, o sistema solicita uma confirmação.

## Resumo

O ator Administrador do Estoque pode:

- Cadastrar produto;
- Listar produtos;
- Visualizar produto;
- Editar produto;
- Excluir produto.
