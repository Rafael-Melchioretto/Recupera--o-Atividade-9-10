# Sistema de Gestão de Estoque

## Sobre o projeto

O Sistema de Gestão de Estoque foi desenvolvido para auxiliar no controle de produtos de um mercado.

O sistema permite realizar o cadastro, consulta, edição e exclusão de produtos armazenados no banco de dados.

## Funcionalidades

O sistema possui as seguintes funcionalidades:

- Cadastro de produtos;
- Listagem dos produtos;
- Visualização dos detalhes;
- Edição de produtos;
- Exclusão de produtos;
- Validação dos dados;
- Tratamento básico de erros;
- Utilização de Prepared Statements.

## Dados dos produtos

Cada produto possui:

- Nome;
- Categoria;
- Descrição;
- Preço;
- Quantidade em estoque;
- Data de validade.

## Tecnologias utilizadas

- PHP;
- MySQL;
- HTML;
- CSS;
- PDO;
- Git;
- GitHub.

Para executar o sistema é necessário possuir:

- PHP;
- MySQL;
